# FRAME / ARCHIVE

「高校生がSony α7 IVとWD Blue 8TBを活用する将来性と現実的な活用法」レポートをもとにした1ページのWebサイトです。

## デザインのコンセプト：「ファインダー × プラッター」
- **ヒーロー**：カメラのファインダーHUD（REC表示、4K60p、AF枠が被写体を探して合焦する動き）
- **色の役割**：インク黒（カメラ本体）／シグナルオレンジ（REC＝撮る）／WDブルー（保存＝残す）／紙色（評価・事例の章）
- **文字**：見出しは Zen Kaku Gothic New、技術データは JetBrains Mono、数字は Archivo Black

## 構成
1. CAMERA — α7 IVの性能と高校生活での使い方
2. STORAGE — WD Blue 8TB（CMR方式）＋ **容量シミュレーター**（写真と動画の配分を操作できる）
3. BACKUP — 3-2-1ルール、取り込みの流れ、バックアップ先の段階、取り扱いチェックリスト
4. IMPACT — 「すごい」と言われる理由、親の説得のコツ、先輩たちの事例
5. FUTURE — 進路4パターン、他分野にも活かせるスキル、成長の好循環
- SOURCES — 脚注番号（sup）をクリックすると対応する出典がハイライトされる

## 起動方法
```
python3 -m http.server 8080
```
静的HTML/CSS/JSのみで動き、ビルドは不要です。
