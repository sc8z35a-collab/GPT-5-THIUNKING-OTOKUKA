STORAGE — WD BLUE 8TB (WD80EAZZ)

ためらわず残せる容量。

8TB

5640 RPM ・ CMR

KEY POINT

8TBモデルは CMR方式。

大容量HDDでは安価なSMR方式が多い中、8TBモデルは上位シリーズ並みのCMR（従来型磁気記録）を採用。大量のファイルを書き込んでも速度が落ちにくく、長期間安定して動作しやすいのが特長です。91112

3-2-1 RULE 18

PIPELINE撮影から保管までの流れ

  1. STEP 01

    撮影

    α7 IVでRAW・4K動画を記録。

  2. STEP 02

    すぐにPCへ取り込む

    メモリーカードのデータは、バックアップが取れるまで消さない。

  3. STEP 03

    WD Blue 8TBにメイン保管

    RAW・動画など大容量データの"本拠地"。

  4. STEP 04

    サブへ分散コピー

    外付けHDD／SSD・クラウド・USBメモリへ。

EXT

外付けHDD・SSD

特に失いたくない写真や作品を、1〜2TB程度の外付けドライブに定期的に差分バックアップ。物理的に別媒体なので安心感が増す。19

定期・差分

CLOUD

クラウドストレージ

学校のGoogle DriveやOneDriveなど。無料の15GB程度でも、編集済みJPEGや書類だけ上げておけばPCが壊れてもアクセス可能。RAW動画は巨大なのでサブ扱いと割り切る。2021

厳選・軽量

USB

暗号化USBメモリ

レポート用写真や卒アル用作品など一部の重要データを。持ち運びや受け渡しに便利だが、紛失リスクに備えて必ずパスワード保護を。2223

小規模・携帯

日常の作業ファイル = クラウド ＋ PC

本格的な大容量データ = WD Blue 8TB ＋ 予備バックアップ 24

FUTURE — CAREER & LEARNING

機材の先に、
進路が見えてくる。

PATH A

専門進学・写真/映像の道

専門学校や美大の写真学科へ。在学中にハイエンド機材で蓄積したポートフォリオが、面接や作品審査で大きな武器に。36

PATH B

在学中から半プロ活動

YouTube・TikTokで本格動画を継続投稿。登録者が増えれば広告収入や企業案件の可能性も。32

PATH C

写真で小さく収益化

ストックフォト出品やコンテスト入賞。写真販売は高校生におすすめの副業として挙げられている。37

現場経験・露出を積む

写真館・ブライダルのアルバイト、観光PRのインターン、学校行事の公式カメラマン。地元メディアに取り上げられれば強い実績に。
